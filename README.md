# AI-ScAMMING-DETECTOR
AI Scam Detector is a simple web-based tool that analyzes suspicious messages and identifies whether they might be scam messages.
It uses keyword analysis to detect common scam patterns such as requests for bank details, OTP, or urgent verification.
This project demonstrates how AI-based logic can help identify potential phishing or scam messages quickly.

🔹Features:
Detects suspicious messages
Identifies common scam keywords
Shows risk level (HIGH / LOW)
Simple and interactive web interface
Real-time analysis using API

🔹Technologies Used
Python
FastAPI
Uvicorn
HTML
JavaScript

🔹How It Works:
User enters a message in the text box.
The frontend sends the message to the backend API.
The backend checks the message for suspicious keywords like:
bank
verify
OTP
password
urgent
The system returns a risk level and reason.
